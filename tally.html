TDL Installation & Usage Guide

How to install and use TDL in Tally:
  1. Click the Download TDL File button on the left to save kcrish_bridge.tdl.
  2. Open TallyPrime and select your company.
  3. Press F1 (Help) > Go to TDL & Add-ons (Shortcut: Alt + O).
  4. Select Manage Local TDLs and set Load TDL files on startup to Yes.
  5. Provide the exact folder path where your kcrish_bridge.tdl is saved.
  6. Once loaded, see Kcrish Automation Hub on Gateway of Tally, or press Ctrl + I to import!
