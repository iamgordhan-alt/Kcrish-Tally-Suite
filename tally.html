TDL Installation & Usage Guide

How to load and use TDL in TallyPrime:
  1. Click Download TDL File to save kcrish_bridge.tdl on your computer.
  2. Open TallyPrime and select your company.
  3. Press F1 (Help) > Select TDL & Add-ons (or shortcut: Alt + O).
  4. Press F4 (Manage Local TDLs) and set Load TDL files on startup to Yes.
  5. Enter the exact file path where kcrish_bridge.tdl is located.
  6. Once loaded, Gateway of Tally par Kcrish Automation Hub menu appear ho jayega!
